# Curriculum Philosophy

## Why PyPractical Exists

Programming is a practical discipline.

Students do not become programmers by reading about programming. They become programmers by designing, writing, testing, debugging, and improving software.

PyPractical exists to provide authentic programming assessments that help students build confidence through practice while reducing the grading workload for teachers.

Every assessment is designed to reinforce the idea that programming is a process of solving meaningful problems rather than memorizing syntax.

---

# Our Beliefs

We believe that students learn programming best when they experience a sequence of small, achievable successes.

Every completed program, no matter how simple, builds confidence for the next challenge.

Confidence is one of the strongest predictors of persistence in programming.

For this reason, PyPractical emphasizes gradual progression rather than unnecessary difficulty.

---

# Learning Progression

Programming concepts should be introduced one at a time.

Each new practical introduces one primary idea while reinforcing previously learned skills.

Students should rarely encounter multiple completely new concepts in a single assessment.

Instead, each practical should feel like a natural extension of what they already know.

---

# Assessment Through Software

Students should write software that resembles programs people actually create.

Instead of isolated algorithm puzzles, assessments should resemble small applications with realistic stories.

Examples include:

- parking garages
- libraries
- Internet cafés
- hospitals
- schools
- restaurants
- hotels

Authentic contexts help students understand why programming exists.

---

# Building Mental Models

Before students can design software, they must first learn to model the real world.

This is especially important during Object-Oriented Programming.

Students should first recognize objects before learning inheritance, polymorphism, or design patterns.

A student who understands that a recorder, book, customer, or reservation is an object already possesses the foundation for more advanced software design.

---

# Simplicity Before Cleverness

The goal of introductory programming is not to write the shortest solution.

The goal is to write software that is correct, readable, and understandable.

PyPractical values clear code over clever code.

Meaningful variable names, simple logic, and readable structure are encouraged throughout the curriculum.

---

# Automatic Assessment

Teachers should spend their time helping students learn rather than manually grading repetitive exercises.

Every practical is designed so that correctness can be verified automatically using unit tests.

Automatic grading provides:

- immediate feedback for students
- consistent grading
- reduced teacher workload
- scalability for large classes

Automation allows teachers to focus on teaching rather than checking syntax.

---

# Authentic Challenge

Good assessments should challenge students without confusing them.

Students should spend their effort solving programming problems rather than deciphering complicated instructions.

Whenever possible:

- stories should be realistic
- instructions should be concise
- vocabulary should be familiar
- objectives should be clear

Difficulty should come from programming, not from reading.

---

# Continuous Improvement

No assessment is ever considered finished.

Every classroom provides feedback.

Every student submission teaches us something.

PyPractical is designed as a living project that continuously evolves through classroom experience.

---

# Open Education

Education improves when teachers share.

PyPractical encourages educators to:

- adapt assessments
- improve assessments
- translate assessments
- contribute new ideas
- report problems
- share classroom experiences

The long-term vision is a community-maintained assessment bank that benefits teachers and students everywhere.

---

# Our Mission

Our mission is simple:

Help teachers spend less time grading and more time teaching.

Help students spend less time memorizing and more time creating.

If students leave a course believing that programming is enjoyable, approachable, and useful, then PyPractical has succeeded.

---


> Every assessment in PyPractical should be good enough that its authors would be happy to use it in their own classroom tomorrow.
